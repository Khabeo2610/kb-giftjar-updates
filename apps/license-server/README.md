# License Server — Dự kiến (giai đoạn 6)

- PostgreSQL, REST API qua TLS.
- License token ký số bất đối xứng (Ed25519); **private key chỉ nằm trên server**, không bao giờ đưa vào app desktop hay repo.
- Kích hoạt thiết bị dựa trên nhiều tín hiệu (không chỉ một mã phần cứng), có quy trình chuyển máy khi thay SSD / cài lại Windows.
- Gói: Trial, Basic, Pro, Studio, Agency — quyền module do chính sách phía server quyết định.

Chưa có mã nguồn — thư mục giữ chỗ.
